# 深度篇：源码级剖析

本篇在基础篇的整体认知上，深入源码级别剖析每个子系统的设计决策和实现细节。

每章包含：
- **源码级流程分析** — 关键函数的逐步执行逻辑
- **类型定义** — 核心接口和类型
- **Mermaid 图** — 状态机、时序图、流程图
- **如何自建** — 从最小实现到生产级增强的路径
- **关键文件索引** — 快速定位源码

## 学习目标

- 掌握 Agent Loop 的状态机和完整生命周期
- 理解权限系统的多层防御和 AI 分类器
- 理解多 Provider 路由和模型选择机制
- 掌握 MCP/Skills/插件扩展系统的设计
- 具备自建类似 Agent 系统的能力
