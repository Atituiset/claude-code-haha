# Claude Code Haha 源码深度分析

本书是对 Claude Code Haha 项目的源码级深度分析，旨在帮助读者：

1. **理解 Agent 运行原理** — 从用户输入到 LLM 调用到工具执行，完整掌握 Agent Loop 的每一步
2. **掌握自建 Agent 的方法论** — 每章末尾提供"如何自建"指南，从最小实现到生产级增强
3. **学习系统设计模式** — 权限管线、并发编排、多路竞争决策、流式执行等可复用的架构模式

## 本书结构

### 基础篇

了解 Agent 的基本运行原理，建立整体认知框架。

### 深度篇

深入源码级别，理解每个子系统的设计决策和实现细节，具备自建类似系统的能力。

## 关于项目

Claude Code Haha 是基于 2026 年 3 月从 Anthropic npm registry 泄露的 Claude Code 源码修复的本地可运行版本，支持接入任意 Anthropic 兼容 API。
